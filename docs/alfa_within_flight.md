# ALFA 同架次时间切分数据集 v1

本协议先选定原始 CSV 文件，再分别在每个文件内部按时间切分，最后将所有文件的训练段、验证段、测试段分别拼接。与原来的按采集组隔离的协议不同，同一源文件会出现在三个 split 中；测试衡量同一架次后续片段的离线检测能力，不能据此宣称对未见架次的泛化性能。原数据和旧版处理目录保留。

## 输入与默认选择

输入为 `data/raw/alfa_20hz_l_18f`，保留原有 18 个特征及其顺序。默认选中全部 46 个有真值的 CSV 文件，排除全为 `-1` 的无真值文件。这里一个 CSV 是一个处理单位，原文件名和采集时间组都保留。可以通过文件清单选择子集，指定清单的顺序也作为拼接顺序；默认按文件名排序。

## 切分规则

令一个文件总点数为 `N`，首次异常的源行号为 `K`（全正常文件取 `K=N`）。默认边界为 `a=floor(0.6*K)`、`b=floor(0.8*K)`：

| split | 源行区间，左闭右开 | 含义 |
| --- | --- | --- |
| train | `[0, a)` | 前 60% 的正常前缀 |
| val | `[a, b)` | 中间 20% 的正常前缀 |
| test | `[b, N)` | 其余正常前缀和完整故障尾段 |

**60/20/20 作用于正常前缀，并非故障文件总长度。** 正常文件整段按此比例切分。训练和验证均无异常，原有异常点完整保留在测试集；每个源行只进入一套数据，无重复或遗漏。用真值故障起点确定切分是本协议的显式假设，标签、时间、来源字段不作为模型输入。

先切分原始点，再建窗口。每个文件的各个分段至少必须有指定窗口大小的点数，短分段直接报错，不自动调比例、不填充、不静默丢弃。默认检查 96 点窗口（20 Hz 下 4.8 秒）；这版含有只有 105 点的验证段，不能直接改为 192 点窗口。

## 归一化与拼接

默认对每个特征使用全体训练段拟合的统一 z-score，标准差按总体计算（`ddof=0`），验证和测试复用该组参数。可单独生成 minmax 版本，同样只拟合训练段，不裁剪超出 `[0,1]` 的值；小于 `1e-12` 的缩放分母设为 1。没有按架次重新拟合或飞行状态校准。

三个 split 各自物理拼接保存，保留 `flight_id`、`source_row`（0 起始的数据行，不含表头）、原始 `time_s` 和 `segment_offsets`。各段时间保持原始含义，跨架次时可跳变或重置，不能把整套拼接数据当作一条连续航迹。

`data.alfa.load_prepared()` 自动识别本协议，并按边界恢复为独立的 `Flight` 分段，可复用现有 `FlightWindows` 和训练脚本。训练窗口步长为 1；验证和测试步长为窗口长度，并补尾窗。窗口不跨架次、不跨 train/val/test 边界，测试尾段所有点均被覆盖。

## 生成命令

在 WSL 本地的 `ltsm` 环境、小规模数据处理即可：

```bash
cd /home/wrj/workspace/uavad
python scripts/prepare_alfa_within_flight.py \
  --output-dir data/processed/alfa_within_flight_v1 \
  --window-size 96
```

选择子集时新建 UTF-8 文本，每行一个完整 CSV 文件名（支持空行和以 `#` 开头的注释），然后执行：

```bash
python scripts/prepare_alfa_within_flight.py \
  --flights-file selected_flights.txt \
  --output-dir data/processed/alfa_within_flight_subset_v1 \
  --train-fraction 0.6 --val-fraction 0.2 --window-size 96
```

已有输出目录拒绝覆盖。数据写入临时目录并完成校验后再整体落到目标目录。

## 输出

- `train.npz`、`val.npz`、`test.npz`：`values` 为归一化的 `(N,18)` float32 模型输入；`raw_values` 为原始 18 特征数值，另含 `labels`、`time_s`、`flight_id`、`source_row`、`segment_offsets`、`features`。均无 Python pickle 对象。
- `train.csv`、`val.csv`、`test.csv`：归一化特征和逐点来源；仅 FEATURES 指定的 18 列作为输入。
- `segments.csv`：每个文件各 split 的源行范围、拼接范围、原始时间与正常/异常点数。
- `selected_flights.txt`：本次选中清单，可用于复建或手动修改子集。
- `scaler.npz`：训练点拟合参数与特征顺序。
- `manifest.json`：协议、比例、选中/未选中/排除文件、源文件哈希、代码哈希及版本、分段、窗口数、输出文件哈希。
- `audit.json`：完整分区、训练/验证无异常、异常完整保留及验证/测试尾窗覆盖的检查结果。

保存后的 NPZ 自包含，不依赖再次读取原始文件。加载时检查 NPZ 和 scaler 的 SHA-256、特征顺序及分段来源映射。

## 验证与后续实验

```bash
python -m pytest -q tests/test_alfa.py tests/test_alfa_within_flight.py
```

测试包括切分比例、逐行互斥与完整性、无真值排除、子集及顺序、训练统计无泄漏、拼接边界、96 点尾窗覆盖、短分段拒绝与输出损坏检查。此次数据处理不启动训练。

后续训练必须指定新目录及 `--window-size 96`，并使用新的结果目录。原版跨架次的指标与这版同架次分段的指标不能直接归因于模型优劣。
